This project needed a bit more planning before I started adding heavy assets. It’s a classic workflow.

I also split every type of asset into collection so I can focus on each group individually.

### Terrain
I started by sculpting the terrain I wanted. I made sure to leave plenty of extra space, so I could move the camera later without exposing any unwanted edges.
It’s always a good idea to have a reference handy. I freestyled this one, though.

Tip for future me: test the lighting at this stage, too.

### Blockout
A great way to visualize how the scene will end up. I used simple shapes like cilinders, spheres, and so on.

Notice the box in the middle of one of the viewport images - it's a person sized reference. Scale is important even at this stage.

### Models
I used some Quixel Megascans assets to fill in the rocks and fallen debris. This is also where I used my own tool, the [BetterMegascan](https://github.com/Zexyp/BetterMegascan) addon. (That’s when I realized I should add automatic proxy creation for use in future projects.)

### Foliage
The heaviest part, I added it at last. That way, my GPU could scream in agony as little as possible. I got to enjoy that lovely message "CUDA crached" quite a few times.
